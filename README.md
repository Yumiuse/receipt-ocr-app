## 抽出データ

- 店名（法人格を除外した屋号のみ）
- 日付（YYYY年MM月DD日形式に統一）
- 合計金額
- 消費税額
- 品目・数量（「商品名 × 数量」形式）
- 支払方法
- 勘定科目提案（3つ）

## 技術スタック

- **フロントエンド**: React.js
- **OCR**: Google Cloud Vision API
- **AI**: OpenAI API (GPT-4o-mini)
- **データ保存**: Google Apps Script + Google Spreadsheet
- **スタイル**: CSS3（グラデーション、アニメーション）

## セットアップ

### 必要なもの

- Node.js (v14以上)
- Google Cloud Vision APIキー
- OpenAI APIキー
- Google Apps Scriptのデプロイ済みURL

### インストール
```bash
# リポジトリをクローン
git clone [your-repo-url]

# ディレクトリに移動
cd receipt-ocr-app

# 依存関係をインストール
npm install
```

### 環境変数の設定

`.env`ファイルを作成：
```
REACT_APP_VISION_API_KEY=your_google_vision_api_key
REACT_APP_OPENAI_API_KEY=your_openai_api_key
REACT_APP_GAS_URL=your_gas_deploy_url
```

### 起動
```bash
npm start
```

ブラウザで `http://localhost:3000` を開く

## 使い方

### 基本的な流れ
1. **画像選択**: 「画像選択」ボタンで1枚または複数枚を選択
2. **画像追加**: 「画像を追加」ボタンで追加選択（既存ファイルは保持）
3. **一括処理**: 「⚡全ファイルを構造化」で並列処理実行
4. **確認・編集**: 各レシートをクリックして内容を確認・編集
5. **保存**: 「💾保存して確定」でSpreadsheetに記録

### ファイル管理
- **追加**: 「画像を追加」で1個ずつ追加可能
- **削除**: 各レシートの右上「×」ボタンで個別削除
- **全削除**: 「🗑️すべてクリア」で全ファイルをクリア

### フィルタ機能
- **全て**: 全ファイルを表示
- **未処理**: まだOCR/構造化していないファイル
- **AI下書き済**: 構造化済みで未保存のファイル
- **確定済**: Spreadsheetに保存済みのファイル

### 順不同処理
- どのファイルから処理しても自動的に次の未処理ファイルへ移動
- 「📝未処理のファイル（X/Y）を表示しました」と案内

## Google Apps Script設定

1. Google Spreadsheetを作成
2. 拡張機能 → Apps Script
3. `コード.gs`に以下をコピー：

```javascript
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = JSON.parse(e.parameter.payload);
  
  sheet.appendRow([
    new Date(),
    data.店名,
    data.日付,
    data.合計金額,
    data.消費税額,
    data.品目.join(', '),
    data.支払方法,
    data.勘定科目提案.join(', ')
  ]);
  
  return ContentService.createTextOutput('Success');
}
```

4. デプロイ → ウェブアプリ → 「全員（匿名を含む）」
5. URLを`.env`に設定

## 💡 技術的な工夫点

### パフォーマンス最適化
- **並列処理**: 複数ファイルを同時処理で大幅な時間短縮
- **画像圧縮**: Vision API送信前に画像を圧縮（最大1200px）
- **AbortController**: 処理中断機能でユーザビリティ向上

### OCR精度の向上
- **AIプロンプトの最適化**: OCR誤認識（「血」→「皿」など）を自動修正
- **店名抽出の改善**: 法人格を除外して屋号のみ抽出
- **日付フォーマット統一**: 様々な形式を YYYY年MM月DD日 に統一
- **言語ヒント追加**: OCR処理で日本語を優先指定

### 技術的課題の解決
- **CORS問題**: FormData + no-cors モードで解決
- **状態管理の複雑化**: React Hooksで複数ファイルの状態を効率的に管理
- **インデックス再調整**: ファイル削除時のインデックスずれを自動修正
- **非同期処理の最適化**: Promise.all()で並列化

### UI/UXの工夫
- **3カラムレイアウト**: レシート一覧 / プレビュー / データ表示
- **処理状況の可視化**: リアルタイム進捗表示とステータス管理
- **直感的な操作**: ドラッグ&ドロップ感覚のファイル管理
- **スマートな画面遷移**: 未処理ファイルを自動検索して表示
- **色彩設計**: 紫系グラデーションで統一した洗練されたデザイン
- **削除ボタンの配置**: 各アイテムに小さく配置し誤操作を防止
