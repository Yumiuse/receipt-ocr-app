## 抽出データ

- 店名（法人格を除外した屋号のみ）
- 日付（YYYY年MM月DD日形式に統一）
- 合計金額
- 消費税額
- 品目・数量（「商品名 × 数量」形式）
- 支払方法
- 勘定科目提案（3つ）

## 技術スタック

- **フロントエンド**: React.js
- **OCR**: Google Cloud Vision API
- **AI**: OpenAI API (GPT-4o-mini)
- **データ保存**: Google Apps Script + Google Spreadsheet
- **スタイル**: CSS3（グラデーション、アニメーション）

## セットアップ

### 必要なもの

- Node.js (v14以上)
- Google Cloud Vision APIキー
- OpenAI APIキー
- Google Apps Scriptのデプロイ済みURL

### インストール
```bash
# リポジトリをクローン
git clone [your-repo-url]

# ディレクトリに移動
cd receipt-ocr-app

# 依存関係をインストール
npm install
```

### 環境変数の設定

`.env`ファイルを作成：
```
REACT_APP_VISION_API_KEY=your_google_vision_api_key
REACT_APP_OPENAI_API_KEY=your_openai_api_key
REACT_APP_GAS_URL=your_gas_deploy_url
```

### 起動
```bash
npm start
```

ブラウザで `http://localhost:3000` を開く

## 使い方

### 単一ファイル処理
1. **画像選択**: 「画像選択」ボタンをクリックしてレシート画像を選択
2. **OCR実行**: 「OCR実行」ボタンで文字認識
3. **構造化**: 「構造化」ボタンでデータを整理
4. **編集**: 必要に応じて「編集」ボタンで修正
5. **保存**: 「保存して確定」でSpreadsheetに記録

### 複数ファイル一括処理（NEW!）
1. **複数選択**: Shiftキーを押しながら複数のレシート画像を選択
2. **一括処理**: 「全ファイルを一括処理」ボタンをクリック
3. **確認・編集**: 各ファイルの構造化データを確認・編集
4. **保存**: 「保存して確定」で次のファイルへ自動遷移

## Google Apps Script設定

1. Google Spreadsheetを作成
2. 拡張機能 → Apps Script
3. `コード.gs`に以下をコピー：

[GASコードへのリンクまたは説明]

4. デプロイ → ウェブアプリ → 「全員（匿名を含む）」
5. URLを`.env`に設定

## 💡 技術的な工夫点

### OCR精度の向上
- **AIプロンプトの最適化**: OCR誤認識（「血」→「皿」など）を自動修正
- **店名抽出の改善**: 法人格を除外して屋号のみ抽出
- **日付フォーマット統一**: 様々な形式を YYYY年MM月DD日 に統一

### 技術的課題の解決
- **CORS問題**: FormData + no-cors モードで解決
- **状態管理**: 複数ファイルの構造化データを効率的に管理
- **非同期処理の最適化**: ユーザー体験を損なわない処理フロー

### UI/UXの工夫
- **左右2カラムレイアウト**: 画像とデータを同時確認
- **処理状況の可視化**: 複数ファイル処理時の進捗表示
- **直感的な操作**: ファイルタブクリックで即座に切り替え
- **スマートな画面遷移**: 保存後に自動的に次のファイルへ
- **色彩設計**: 紫系グラデーションで統一した洗練されたデザイン
